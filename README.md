# Cognitive Quest

## An AI-Driven Adaptive Strategy Game Using Search, CSP and Knowledge-Based Reasoning

Cognitive Quest is a Pygame-based AI strategy game developed as a mini-project.

The game demonstrates several Artificial Intelligence techniques through an interactive game environment.

## AI Techniques Used

- Breadth First Search (BFS)
- Depth First Search (DFS)
- A* Search
- Constraint Satisfaction Problem (CSP)
- Backtracking
- Knowledge-Based Reasoning
- Forward Chaining
- Backward Chaining
- Minimax
- Adaptive Difficulty
- AI Decision Logging

## Game Objective

The player must:

1. Navigate through the grid.
2. Find the key.
3. Reach the security door.
4. Solve the CSP security puzzle.
5. Unlock the door.
6. Collect the treasure.
7. Reach the goal.
8. Avoid the intelligent enemy.

## Technologies Used

- Python
- Pygame Community Edition
- Artificial Intelligence algorithms
